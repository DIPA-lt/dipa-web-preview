01 Qualification

This stage fits if you have strong users, but practice does not leave their heads

We define scope in a 30-minute call, then give a concrete number. We start with one team, not the whole organisation.

It fits if

  • → Some people already work well with AI
  • → Everyone still works their own way
  • → You can appoint an owner who will keep the standard alive
  • → There is an agreed task that can be measured

It does not fit if

  • ✕ Nobody in the organisation uses AI on purpose yet — start at stage 1
  • ✕ You want to change the process itself — that is the Sprint
  • ✕ There is no person who will stay accountable after the project
  • ✕ The aim is company-wide training in one go
02 Outcomes

What you will have if the best person left

The test is simple: if your best AI user left tomorrow, would their method remain as a skill, playbook or workflow?

01

Captured practice

03

KPI and baseline

Starting state and metrics for an agreed task: quality variance, onboarding, rework, output/FTE.

03 How it runs

From a head into a system

We do not write a standard in a conference room. We take the best live work and turn it into a team rule.

1 · SELECT

One team, one agreed task, one owner.

2 · EXTRACT

The best user's method documented and checked with others.

3 · STANDARD

Skill / playbook / workflow. The team starts working the same way.

4 · MEASURE

Baseline and first comparison. Then: keep, expand, or move to stage 3.

If the best user left, the method must remain. Otherwise you are still at stage 1.

04 Measurement
VARIANCE

The same work — more even quality across the team.

ONBOARDING

A new person reaches the standard faster, not by watching from the side.

REWORK

Fewer fixes, because the method is one.

OUTPUT / FTE

More finished work per person — if the hours are converted.

05 Common questions
Why is the price “by scope”, not like €999?
Stage 1 is a seat. Stage 2 depends on team size, number of tasks and how much practice is already captured. After a 30-minute call we give a concrete number. We do not guess in public.
Is this the same as the Transformation Sprint?
No. Here we change team competence. The Sprint changes the work itself — the process map, Human + AI boundaries, 90 days to GATE. A standard without a redesigned process still speeds up the old work.
Do we need to complete stage 1 first?
If leaders already know how to judge AI competence and the team has a strong user — you can start here. If AI is still random, stage 2 will have nothing to capture.

Name the team that already can, but unevenly

A 30-minute scope call. If we see you need stage 1 or 3 — we will say so immediately.
