02 Why an overlay, not a system

OPPM does not replace Jira, SAP or PMBOK

It translates that dense work into one view you can read in two minutes. It replaces a communication habit, not project-management software.

Five mandatory fields

Tasks, objectives, time, cost, owners. If one is missing, it is still activity, not a project.

One language across projects

A leader can review a sales sprint and a data project without translating formats.

Lean and A3 logic

Objectives at the top, work below. Strategy linked to the people who execute.

Works for a sprint or for agile

Phases can become releases and sprints. The matrix stays the same.

If project health cannot be shown on one page, leadership is not seeing it.

03 Anatomy

05 Common questions
Can we buy OPPM without the sprint?
Not as a default SKU in this prototype. The method works when there is a real project with a baseline, an owner and a GATE. Without that the board becomes an empty template. If you have your own project portfolio and only want a communication standard, say so in the enquiry — we will treat that as a separate decision, not the listed product.
Does this replace our Jira / Monday / Excel?
No. The team keeps working where it already works. OPPM is the layer above: what matters to leadership and to GATE. If detail and summary live in the same file, both become useless.
Whose method is this?
Clark A. Campbell developed the One-Page Project Manager at O.C. Tanner, influenced by visual practice at DuPont. We do not rebrand it. We use it as a layer on our eight phases and five filters — and we hand it over with the sprint.
